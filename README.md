# open-munch-game

Реализация базовой карточной игры «Манчкин» для некоммерческого использования

Сессия игры на одного игрока человека, остальные 3-6 игроков – боты

Минимум графики, достаточно краткого описания карточек

Платформа: telegram app (основная), возможность запускать в браузере для разработки

Стек технологий: angular v21+ (OnPush, Zoneless), nodejs v24+, 100% покрытие typescript v5+

Вёрстку делай на базовых html элементах с css только для положения элементов

Минимум дополнительных зависимостей, используем по максимому лучшие практики angular и инструменты «из коробки»

Пиши юнит и интеграционные тесты актуальными инструментами под angular v21+, добивайся покрытие тестами 80% основных кейсов

Декомпозируй проект на небольшие задачи, отмечай задачи которые выполнил

Веди CLAUDE.md, специфичные доменные знания выноси в скилы, обращайся к этим скилам только если задача затрагивает эту доменную зону
